Bubble Sort

Repeatedly swaps adjacent elements if they are in the wrong order. Simple but slow — like bubbles rising to the surface.

Best: O(n) Avg: O(n²) Space: O(1)

Selection Sort

Finds the minimum element and places it at the beginning repeatedly. Makes fewer swaps than Bubble Sort.

Best: O(n²) Avg: O(n²) Space: O(1)
O(n²)

Insertion Sort

Builds a sorted array one item at a time by inserting each element into its correct position. Efficient for small arrays.

Best: O(n) Avg: O(n²) Space: O(1)
