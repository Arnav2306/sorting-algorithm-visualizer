Bubble Sort

Repeatedly steps through the array, compares adjacent elements, and swaps them if they are in the wrong order. Quadratic worst/average cases make it impractical for large sets.

Best: O(n) Avg: O(n²) Worst: O(n²) Space: O(1)
O(n²)
Unstable

Selection Sort

Repeatedly scans the unsorted partition to find the minimum element and moves it to the sorted prefix. Performs minimal swaps (O(n)) but always requires O(n²) comparisons.

Best: O(n²) Avg: O(n²) Worst: O(n²) Space: O(1)
O(n²)
Stable

Insertion Sort

Builds the final sorted array one item at a time by inserting each element into its proper position. Highly efficient for small or nearly sorted datasets (adaptive O(n) best case).

Best: O(n) Avg: O(n²) Worst: O(n²) Space: O(1)
O(n log n)
Stable

Merge Sort

Divide-and-conquer algorithm that recursively divides array into halves, sorts them, and merges sorted sequences. Guarantees predictable O(n log n) runtime at the cost of O(n) auxiliary space.

Best: O(n log n) Avg: O(n log n) Worst: O(n log n) Space: O(n)
O(n log n)
Unstable

Quick Sort

Partitions the array around a chosen pivot so elements smaller than the pivot precede larger ones, then recurses. Excellent cache performance and practical speed; worst-case O(n²) on unbalanced pivots.

Best: O(n log n) Avg: O(n log n) Worst: O(n²) Space: O(log n)
